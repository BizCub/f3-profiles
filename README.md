## Debug Screen Option Profiles

The "Debug Screen Option Profiles" mod simplifies working with the debug screen. It allows you to save settings and quickly switch between them using profiles. Now you don't need to copy files manually.

![preview](https://cdn.modrinth.com/data/cached_images/593daaa0ab9c3fbbc6a0c42df960fcddb627a065_0.webp)

## Usage

To open the profiles menu, press the debug screen hotkey (default: ```F3 + F6```) and select ```Presets``` Here you can create, edit, apply, and delete profiles. Once applied, a profile becomes active by default, and all changes in the main menu will be saved to it.

## Additional

* Profiles are stored in the ```config/debug-option-profiles folder```.
* Fabric API is required for mod translation (if available). Otherwise, it is not required.
* When renaming a profile, there are restrictions on existing names and unsupported characters.
